# UI/UX 정리

2026-11-02 추가 개선과 현재 미완료 항목은 [디자인·기능 점검](design-audit-2026-11-02.md)을 참고한다. 피그마 원본 링크는 아직 연결되지 않았으며 이번 시안은 기존 코드와 이미지로 구현했다.

따뜻한 흰색 바탕, 버건디 포인트, 여백과 일정한 모서리 곡률로 정리했다. 줄무늬와 배경 장식을 제거하고 카드 그림자·테두리 강도를 줄였다. 입력 필드는 16px로 맞춰 iOS 입력 시 확대를 줄이고 터치 영역과 키보드 포커스를 보강했다.

## 탐색과 화면 전환

- 하단 메뉴를 홈·기록·룩 추가·스타일·옷장으로 통일하고 모든 탭의 현재 위치를 표시한다.
- 탭 이동의 스크롤은 Next.js 기본 동작으로 통일했다. 별도의 지연 스크롤 복원과 강제 제목 포커스를 제거해 화면이 다시 튀지 않도록 했다. 설문 단계와 기록 단계는 새 단계의 맨 위에서 시작한다.
- 설문에 명시적인 이전 단계 링크를 추가하고 뒤로 갔을 때 선택을 유지한다. 프로필 수정에는 옷장으로 돌아가는 경로를 제공한다.
- 로딩 화면과 오류 재시도를 추가하고 인증 연결 오류가 무한 대기로 남지 않도록 처리한다.
- 로그인·설문 건너뛰기·기록 상세 창은 Escape, Tab 포커스 순환, 배경 스크롤 잠금과 종료 후 포커스 복원을 지원한다.
- 링크 안에 버튼이 중첩된 UI를 링크 버튼으로 바꿨다.

## 주요 흐름

- 첫 홈 진입 시 AI 호출 대신 추천 버튼을 보여준다. 중복된 레벨 혜택 카드는 줄이고 주요 동작을 먼저 보여준다.
- 기록에는 이전 단계, 분석 재시도, 분석 없이 기록을 제공한다. 저장 실패 시 오류를 표시하며 성공 처리나 화면 이동을 하지 않는다. 중복 저장을 차단한다.
- 작성 중 다른 링크로 이동하거나 페이지를 새로고침하면 이탈 확인을 제공한다. 브라우저 히스토리의 뒤로/앞으로 이동에는 별도 차단을 구현하지 않았다.
- 최근 사진은 해당 날짜의 기록 상세로 연결한다. 기록 편집·삭제도 실제 저장 결과를 확인하고 실패 시 내용을 유지한다.
- 프로필 공유와 소개 복사를 분리한다. 아직 공개 프로필 URL은 없으므로 개인 화면 주소를 공개 공유 링크처럼 전달하지 않는다.
- 문의는 한글 IME 조합 중 Enter 전송을 막고 입력 길이와 서버에 전달하는 대화 길이를 제한한다. 전송 실패 시 입력을 복구한다.
- 설문 완료는 서버 저장이 성공한 후 이동한다. 실패 시 선택을 유지하고 재시도할 수 있다.
- 예전 분석 결과와 첫 기록 화면에 남아 있던 가짜 통계·샘플 사진·기본 메모를 제거했다. 실제 사진과 분석만 표시하며 사진이 없으면 선택 화면으로 안내한다. 첫 기록 메모도 실제 저장한다.

## 확인 방법

`npm run build` 후 `npm run test:ui`로 모바일 Chromium 검증을 실행한다. Playwright Chromium 설치가 필요하다. 캡처는 `artifacts/ui/`에 생성된다.

브라우저 테스트는 가짜 로그인 세션과 API 응답을 사용한다. 실제 사용자 계정, Supabase 데이터, Gemini 과금은 사용하지 않는다. 실제 iOS 키보드·카메라·Keychain·뒤로 가기 제스처는 최신 Xcode의 실기기로 별도 확인해야 한다.


## 실행 순서로 다시 점검한 수정

이전 검증은 버튼의 존재와 클릭에 치우쳐 실제 높이와 위치를 놓쳤다. 이번에는 시작 → 회원가입 → 프로필 → 스타일 → 색상 → 핏 → 홈 추천 → 사진 선택 → 분석 → 메모/저장 → 타임라인 → 상세 수정/저장/닫기 → 스타일 → 옷장 → 프로필 수정/복귀 → 문의 전송/복귀를 연속으로 실행했다. 기존 계정 로그인도 별도 실행했다.

- 정의되지 않은 h-13 대신 실제 52px 높이를 지정해 회원가입과 로그인 입력칸·버튼 높이를 복구했다.
- 과도하게 커진 공통 radius 값을 12px로 되돌리고 카드와 입력 요소의 크기를 구분했다.
- 설문의 overflow-hidden 부모와 sticky footer 조합을 제거했다. PageActions는 portal로 페이지 바깥에 고정하고 ResizeObserver로 실제 높이만큼 콘텐츠 공간을 확보한다.
- 기록을 3단계로 정리하고 분석·진행·저장 버튼은 하단 메뉴 위에 배치했다. 사진 미리보기 높이는 화면 높이에 맞춰 제한한다. 분석 취소와 분석 없이 기록하기를 제공한다.
- 첫 화면의 가짜 로딩과 지연 등장 효과를 제거했다. 상세 기록에는 상단 닫기 버튼을 추가하고 편집/삭제의 터치 영역을 확대했다.
- 주요 동작은 최소 44px 높이, 뷰포트 내 위치, elementFromPoint로 실제 클릭 가능한 위치인지 검증한다.

일반 휴대폰, 320×568 작은 화면, 1280×800 데스크톱에서 브라우저 검증 11개 통과. 보안/설정 테스트 8개와 웹 빌드도 통과했다. 실행 순서별 뷰포트 캡처는 artifacts/journey/{phone,compact,desktop}/에 저장한다. 이전 전체 페이지 캡처는 하단 고정 요소가 중간에 나타나 실제 화면처럼 평가하기 어려웠으므로 새 캡처는 각 시점의 뷰포트만 사용한다.

브라우저 테스트는 인증·AI 응답을 모의 처리한다. 실제 계정의 가입·서버 과금·네이티브 키보드 동작을 검증했다는 의미는 아니다.
